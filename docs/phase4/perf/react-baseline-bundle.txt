#   - 源码 + vendor chunks估算

#   semi-icons: ~50KB
#   其他 (@vercel/*, @dnd-kit/*): ~20KB
#   源码 (src/): ~100KB gz (JSX + business logic)
#   vendor chunks (lodash, etc.): ~50KB
# - Vite build 估算（生产环境 gzip）：
#   chunks: main.js + vendor.js + polyfills.js + Monaco chunk
#   总计约 820KB gz（含 Monaco lazy chunk）
# - 不含 Monaco 时（普通 CRUD 使用）：约 620KB gz
