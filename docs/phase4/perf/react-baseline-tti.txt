#   5. NotesContextProvider: notes array
#   6. AreasContextProvider: areas array
#   7. TasksContextProvider: 任务上下文
#   8. SelectContextProvider: selectedElement state
#   9. UndoRedoContextProvider: undo/redo stacks
#   10. TransformContextProvider: pan/zoom transform
#   11. LayoutContextProvider: 最外层，layout config
#   12. WorkSpace: 渲染 EditorCanvas + panels
