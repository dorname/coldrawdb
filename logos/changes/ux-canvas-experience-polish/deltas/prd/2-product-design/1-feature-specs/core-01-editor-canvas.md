## MODIFIED — §3.3 滚轮缩放光标锚定（V1.1）

将滚轮缩放因子从 `1.1` 调整为 `1.15`，每次滚动放大/缩小 15%，减少快速定位所需轮数。工具栏 `zoom_in` / `zoom_out` 保持既有 `1.25x` 步长不变。锚定不变量与 clamp 口径保持不变。

更新后的公式：

```
factor = 1.15（滚上） / 1/1.15（滚下）
new_zoom = clamp(zoom × factor, ZOOM_MIN, ZOOM_MAX)
```

提升关系线默认视觉权重，使其在复杂画布中更醒目：

- 默认主线宽度：`2.0px` → `2.5px`
- 默认光晕宽度：`7.0px` → `8.0px`

- 选中关系自身光晕宽度：`10.0px` → `12.0px`

上述数值作为 UI 合同，由 `UT-PE-HL-01` 源码断言锁定。
