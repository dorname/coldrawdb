## ADDED — 关系工具拆分图标

| 图标 ID | 用途 | 占位符 | 使用位置 |
|---|---|---|---|
| `IconRelationshipCreate` | 创建关系工具 | `🔗` | ToolRail `cdb-tool-rail-relationship-create` |
| `IconRelationshipSelect` | 选中关系工具 | `↖`（或指针箭头） | ToolRail `cdb-tool-rail-relationship-select` |
