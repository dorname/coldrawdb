## ADDED — §5.18 统一选择、拖动与平移（#63）

| 合同 ID | 条款 |
|---|---|
| R-SEL-UNIFY-01 | 默认 ToolRail 工具名称为「选择 / 平移」，`tool-pan` 标识保持不变；表头/表体用于选择或拖动，空白用于点击清选或拖动平移，名称必须与真实行为一致。 |
| R-SEL-UNIFY-02 | 默认选择工具与选中关系工具均允许点选表并直接拖动，不得要求先切换到其他工具；pointerdown 后立即显示既有选中环，拖动中显示 `grabbing` 光标。 |
| R-SEL-UNIFY-03 | 选中关系工具命中关系线时，沿用 `hit_test_reference_tier` 的最近距离与叠线轮选规则选择关系；不得发起 `PickSource / PickTarget / Dragging` 建关系手势。 |
| R-SEL-UNIFY-04 | 选中关系工具未命中关系时，必须回落到统一图元路由：表/便签/区域按既有规则选择与拖动，空白按 §5.15 清选或平移；不得因工具提前 return 而吞掉事件。 |
| R-SEL-UNIFY-05 | 选中关系工具下字段连接点不得发起新关系；该限制不得阻断表体选择、表拖动或空白平移。创建关系工具仍保留字段拖线与两点创建语义。 |
| R-SEL-UNIFY-06 | 工具切换本身不新增 diagram 数据、不进入撤销栈、不写协作 op；只有实际图元拖动/编辑才沿用既有持久化通道。 |
| R-SEL-UNIFY-07 | 只读/Viewer 下仍可选中图元并平移视图，但拖动不得写入文档；权限口径不因统一路由而放宽。 |
| R-SEL-UNIFY-08 | 框选工具的空白框选、多表累加与整组拖动语义保持不变；默认拖表、叠线轮选和空白平移既有验收必须继续通过。 |

**验收口径**：激活「选中关系」后，点线选中关系；点表选中并显示 Inspector；拖表松手位置与协作文档一致；字段端口按下/移动不得新增关系；空白拖动只改变视口并保留选中。全过程不需要切换默认工具，且不存在无反馈的点击区域。
