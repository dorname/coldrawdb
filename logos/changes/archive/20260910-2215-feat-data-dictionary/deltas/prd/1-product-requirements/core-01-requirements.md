# Delta — core-01-requirements.md（新增 S07 数据字典需求）

## ADDED — 3.2 数据字典功能性需求（S07 / V3）

> 数据字典 = PDManer 式**代码映射表管理**：集中定义字段可枚举取值及含义（如 `0=否/1=是`），供字段绑定复用。与 Enum（core-01c，存储类型级枚举）互补：Enum 决定字段存储类型，数据字典描述字段取值的业务语义映射。

| US ID | 用户故事 |
|---|---|
| US-25 | 作为数据库设计者，我希望集中管理代码映射字典（名称+编码+value/label 字典项），以便多表字段复用同一套枚举语义 |
| US-26 | 作为数据库设计者，我希望在字段上绑定字典，以便字段注释/导出文档中体现取值映射 |
| US-27 | 作为数据库设计者，我希望删除被引用字典时获得提示，以避免字段绑定悬空 |
| US-28 | 作为数据库设计者，我希望导出数据字典文档（Markdown），以便随表结构文档分发评审 |

| FR ID | 需求 | 验收条件 | 对齐能力 |
|---|---|---|---|
| FR-25 | 数据字典 CRUD（字典：名称+编码；字典项：value/label/排序） | 侧栏字典 Tab 可增删改查；同图内字典编码唯一 | CAP-DICT-01 |
| FR-26 | 字段绑定数据字典（软引用，按字典编码） | Inspector 字段卡可选绑定/解绑；解绑不影响字段本身 | CAP-DICT-02 |
| FR-27 | 字典随 diagram JSON 快照持久化 | 保存后重开字典仍在；旧图无 `dictionaries` 字段时默认为空（向前兼容） | CAP-PERSIST-01 |
| FR-28 | 删除被引用字典需确认 | 提示「被 N 个字段引用」；确认后字段绑定置空 | CAP-DICT-03 |
| FR-29 | 数据字典 Markdown 导出 | 导出含字典清单、各字典映射表、字段绑定关系表 | CAP-DICT-04 |

## ADDED — 6.2 S07 数据字典验收条件（规格级）

- [ ] 字典 CRUD + 字典项编辑在侧栏字典 Tab 可演示
- [ ] 字段绑定字典后，字典 Tab 可见引用计数；删除被引用字典出现确认
- [ ] 字典随自动保存持久化，刷新/重开后完整恢复；无字典的旧图加载不报错
- [ ] Markdown 导出内容与当前模型一致（字典项序、绑定关系）
- [ ] Viewer 只读：字典编辑与绑定控件禁用，导出可用
