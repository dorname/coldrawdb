## ADDED — §4.10 表检查器相关关系明细与定位（#66）

- **R-REL-LIST-01 触发与范围**：`SelectionKind::Table(table_id)` 且 Inspector 打开时，在表检查器中显示“关系”区。集合包含 `start_table_id == table_id` 的出边、`end_table_id == table_id` 的入边；自环只显示一次并标记“自环”。不得用会排除自环或合并同对端多关系的关联表集合代替关系集合。
- **R-REL-LIST-02 明细内容**：每条关系显示方向、关系名、完整字段对、显示化基数和 `ON DELETE`；空名回退与 R-HOV-02 一致。每一条 reference 独立成行，即使端点表相同也不得合并。
- **R-REL-LIST-03 稳定顺序与空态**：列表保持 `references` 数据顺序；当前表无关系时显示“当前表暂无关系”。
- **R-REL-LIST-04 点击定位**：每条明细为按钮，测试标识 `inspector-table-relation-<reference_id>`。点击后写入 `SelectionKind::Reference(reference_id)`、保持 Inspector 打开并展示既有关系检查器，同时触发 R-HL-REF-01～03 的画布高亮；不得自动平移或缩放画布。
- **R-REL-LIST-05 无副作用**：查看和定位不改数据，不触发 dirty、保存、撤销命令或协作 op；Viewer / 只读模式同样可用。

## ADDED — §4.11 上下文与全局关系标签（#65 / #66）

- **R-REL-LABEL-01 默认安静、上下文优先**：本机偏好 `cdb.relation-labels` 支持 `off` / `on`，缺省和非法值回落 `off`。浮动工具条提供 `canvas-relation-labels` 开关，文案明确显示“关系标签：关/开”，切换后立即重绘并持久化；不写 diagram、不进撤销栈、不同步协作，只读可用。
- **R-REL-LABEL-02 上下文自动标签**：全局开关关闭时，选中关系仍显示该关系标签，选中一个或多个表时显示所有相关关系标签；无选中时不显示线旁标签。全局开关打开时显示全部可见关系的标签。上下文标签不依赖用户再打开全局开关。
- **R-REL-LABEL-03 标签内容**：每个标签最多两行：第一行关系名 + 显示化基数，第二行完整字段对；空名回退与 R-HOV-02 一致。`ON DELETE` 保留在悬停和检查器中，不塞入线旁标签。文字按可用宽度截断，最大屏幕宽度 240px，避免长名侵占画布。
- **R-REL-LABEL-04 同源位置**：标签锚点必须消费与绘制相同的 `line_type`、Tier、comment_mode、zoom 和有效字号几何。贝塞尔取 `t=0.5`，直线取端点中点，正交折线按总路径长度取中点，不得另用端点直线近似替代实际路径。
- **R-REL-LABEL-05 屏幕可读性**：标签字号随本机画布字号倍率变化，屏幕字号不低于 10px；使用主题感知的半透明衬底、边框与前景色，保证亮暗主题可读。标签只绘制，不截获指针事件，不改变既有关系命中。
- **R-REL-LABEL-06 碰撞与优先级**：以路径中点为中心尝试上下交替的候选偏移；标签之间及标签与可见表卡之间进行 AABB 碰撞检测。布局顺序为选中关系 > 选中表相关关系 > 其他普通关系；高优先级标签先占位。普通标签所有候选位置均冲突时省略，不得相互叠字；完整信息仍可通过悬停和检查器获得。
- **R-REL-LABEL-07 视口与性能**：只布局与视口相交且端点可解析的关系；复用每帧既有 table map 和路径几何，不新增持久化状态或后台任务。平移、缩放、拖表和维度/注释切换后标签随同一帧几何更新。
- **R-REL-LABEL-08 可验证性**：实际完成绘制的标签写入 `window.__cdb_relation_label_probe`，至少包含 `show_all`、`visible_ids` 和因碰撞省略的 `skipped_ids`；探针只能反映真实绘制结果，不得把“候选关系”误报为“可见标签”。

**验收口径**：UT-PB-34 验证关系明细；UT-PB-35 验证偏好解析、标签内容/显隐、路径中点和碰撞规则；ST-PB-18 验证大图表关系明细与定位；ST-PB-19 验证完整悬停、上下文标签、全局标签、刷新偏好、遮挡省略和无写入副作用。
