# Delta: core-01-editor-canvas.md — 密集关系下统一选择与拖表（#74）

## MODIFIED — §5.18 统一选择、拖动与平移（#63）

| 合同 ID | 条款 |
|---|---|
| R-SEL-UNIFY-01 | 默认 ToolRail 工具名称为「选择 / 平移」，`tool-pan` 标识保持不变；表头/表体用于选择或拖动，空白用于点击清选或拖动平移，名称必须与真实行为一致。 |
| R-SEL-UNIFY-02 | 默认选择工具与框选工具命中表头/表体时一律优先表并允许直接拖动，不得因同时命中关系热区而改选关系；选中关系工具在未命中关系时同样允许点选表并直接拖动，不得要求先切换到其他工具。pointerdown 后立即显示既有选中环，拖动中显示 `grabbing` 光标。 |
| R-SEL-UNIFY-03 | 选中关系工具命中关系线时，沿用关系命中函数的最近距离与叠线轮选规则选择关系；该函数必须使用与 Canvas 绘制相同的 Tier、comment_mode、zoom 与 label_font_scale 有效几何；不得发起 `PickSource / PickTarget / Dragging` 建关系手势。 |
| R-SEL-UNIFY-04 | 选中关系工具在当前有效几何下未命中关系时，必须回落到统一图元路由：表/便签/区域按既有规则选择与拖动，空白按 §5.15 清选或平移；不得因工具提前 return 而吞掉事件，也不得使用旧 `1.0 / 1.0` 几何制造不可见关系命中。 |
| R-SEL-UNIFY-05 | 选中关系工具下字段连接点不得发起新关系；该限制不得阻断表体选择、表拖动或空白平移。创建关系工具仍保留字段拖线与两点创建语义。 |
| R-SEL-UNIFY-06 | 工具切换本身不新增 diagram 数据、不进入撤销栈、不写协作 op；只有实际图元拖动/编辑才沿用既有持久化通道。 |
| R-SEL-UNIFY-07 | 只读/Viewer 下仍可选中图元并平移视图，但拖动不得写入文档；权限口径不因统一路由而放宽。只读没有拖表写入风险，关系与表的优先级继续遵循 core-01b §4.7 R-HIT-05 的只读近线优先条款。 |
| R-SEL-UNIFY-08 | 框选工具的空白框选、多表累加与整组拖动语义保持不变；默认拖表、显式关系选择、叠线轮选和空白平移既有验收必须继续通过。54 表 / 97 关系密度下同样必须满足，不得以稀疏模型回归替代密集场景。 |

**验收口径**：默认选择或框选工具中，即使关系路径/热区穿过表头或表体，真实 pointerdown + move 仍选中并拖动表；激活「选中关系」后，点击有效可见关系仍选中关系，未命中关系时点表、拖表和空白平移正常。低缩放及画布字号放大后不得命中旧几何上的不可见关系。54 表 / 97 关系回归由 ST-PB-21 承接，既有 ST-PB-16/17/20、ST-CR-02、ST-CR-MULTI-01、ST-CR-PAN-02 不得回归。

## ADDED — §5.19 悬浮控件指针边界（#74）

| 合同 ID | 条款 |
|---|---|
| R-FLOAT-HIT-01 | `.cdb-floating-controls` 的容器背景、padding、gap、分隔和缩放文本等非按钮区域不得截获画布 pointerdown；这些位置的事件必须穿透到下方 Canvas，表拖动与空白平移不被阻挡。 |
| R-FLOAT-HIT-02 | 缩放、注释、维度、关系标签、字号等实际按钮继续接收指针并执行既有命令；指针穿透不得扩大或缩小按钮既有可点区域。 |
| R-FLOAT-HIT-03 | 本条款只收窄命中区域，不改变 #69 已修复的网格行约束、z-index、视觉位置或按钮内容；1280×720 与 1440×900 下按钮可点性不得回归。 |

验收由 ST-PB-21 使用真实指针与 `elementFromPoint` 共同覆盖：非按钮采样点命中 Canvas，按钮中心仍命中按钮本身。
