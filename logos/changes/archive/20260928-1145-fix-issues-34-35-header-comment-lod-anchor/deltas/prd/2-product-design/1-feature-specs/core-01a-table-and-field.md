> 目标：#34——R-CMT-CONTRAST-01 的「注释实际渲染位置有效背景」判据明文化为**渐变双端点 worst-case**：满强度 tint 合成端与渐变衰减端（纯表体底色）两端同时 ≥4.5:1 才免 chip。实现此前按满强度 tint 单点评估，渐变中右段（注释实际位置）漏判。

## MODIFIED — §1.7 注释可读性与对比度合同（fix-open-issues-26-33 / #32；fix-issues-34-35 / #34 双端点判据）

> 现状缺口：R-COLOR-04 的表头前景自适应以「表头整体有效背景（单合成色）」计算，但表头为**渐变底**时注释常压在渐变高光/暗部上，单合成色的计算结果在注释实际所在区域不满足可读对比度；字段行注释为浅灰细字，中等缩放即难辨。

| ID | 约束 |
|---|---|
| R-CMT-CONTRAST-01 | 表头注释前景色按**注释实际渲染位置的有效背景**计算。表头为 tint → 透明渐变（135° 族）时，注释区有效背景取**双端点 worst-case**：满强度 tint 合成端（渐变起点）与纯表体底色端（渐变衰减端）**两端同时**参与判定——候选前景（muted → strong → 反向 strong）须在两端对比度均 ≥ 4.5:1 方可免衬底直绘；沿用 R-COLOR-04 的相对亮度阈值口径选定强/次前景对 |
| R-CMT-CONTRAST-02 | 当注释区有效背景与可用前景对的对比度仍低于下限（小字 < 4.5:1，WCAG AA 思路）时，必须启用兜底之一：注释文字下半透明实色衬底（圆角 chip，底色取与注释前景互补的主题色，alpha 建议 0.35～0.55）、或注释区渐变弱化为近实色；不允许「字压渐变高光」出货。chip 兜底同样按双端点合成评估（chip 分别合成到两端背景后取对比度更高方案） |
| R-CMT-CONTRAST-03 | 注释字号/字重下限：表头注释字号 ≥ 表名字号 0.8× 且 ≥ 11px（100% zoom 渲染口径），字重 ≥ 400；字段行注释字号 ≥ 字段名字号 0.85×，字重 ≥ 400；注释与主名保持可区分层级（字号或字重差） |
| R-CMT-CONTRAST-04 | 字段行注释前景相对字段行背景对比度 ≥ 4.5:1（小字口径）；亮/暗主题各自满足；不再使用「浅灰细字」裸色值，统一走主题 token（见 `core-07-design-tokens.md` §15.4）。字段行 tint 入参全透明，双端点退化为同一样本，行为与单端点一致 |
| R-CMT-CONTRAST-05 | 空注释不渲染、不占位（保持 §1.5 既有约定）；本合同不改变注释数据与显示开关行为，仅改渲染层 |

**验收口径**：蓝 / 绿 / 紫 / 橙 / 粉 / 棕六种表头色 × 亮 / 暗主题下，表头注释均可目视读出（含渐变亮段）；字段注释在 100% zoom 清晰、约 70% zoom 仍可辨。
